# TryHackMe – Security Analyst Journey

This folder contains my personal notes and documentation from the **Security Analyst Journey** room on TryHackMe.

The room introduces the day-to-day role of a **Junior Security Analyst (SOC Level 1 Analyst)**, covering the team structure of a Security Operations Center (SOC) and walking through a hands-on simulation of detecting, investigating, escalating, and containing a real security alert.

---

## 🛡️ Topics Covered

- The role and daily duties of a Junior Security Analyst / SOC Level 1 Analyst
- Structure of a SOC team and how each role contributes:
  - Senior Analyst
  - SOC Engineer
  - SOC Manager
  - Incident Responder
- Common challenges a Junior Analyst may face (data-stealer infections, phishing campaigns, ransomware incidents, detection engineering)
- End-to-end alert investigation workflow:
  - Reviewing alerts on a SIEM dashboard
  - Checking IP reputation and location (IP Hunter)
  - Escalating incidents to the correct staff member
  - Blocking malicious IPs on the firewall
