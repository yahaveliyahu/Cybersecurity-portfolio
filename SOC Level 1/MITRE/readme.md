# TryHackMe – MITRE

This folder contains my personal notes and documentation from the **MITRE** room on TryHackMe.

The room introduces MITRE's cyber security frameworks and resources, focusing on how security teams use them to understand adversary behaviour, profile threats, build detections, and strengthen defences.

---

## 🛡️ Topics Covered

- What MITRE is and its role in the security community
- TTPs – Tactics, Techniques and Procedures (and how they differ from IOCs)
- The **MITRE ATT&CK** framework:
  - The Enterprise, Mobile and ICS matrices
  - Tactics, techniques and sub-techniques
  - Technique pages, IDs, mitigations and detection strategies
- How different teams use ATT&CK (CTI, SOC, Detection Engineering, Incident Response, Red & Purple Teams)
- Mapping CTI reports to ATT&CK techniques
- The **ATT&CK Navigator** and its layers
- APT groups and threat profiling:
  - Mustang Panda (G0129)
  - APT33 (G0064) – an aviation sector scenario during a cloud migration
- The **Cyber Analytics Repository (CAR)**:
  - Detection analytics and their implementations (Pseudocode, Splunk, LogPoint)
  - CAR's coverage layer and gap analysis
- The **MITRE D3FEND** framework:
  - Defensive techniques and digital artifacts
  - Credential Rotation and User Behavior Analysis
- Other MITRE projects:
  - Adversary Emulation Library
  - Caldera
  - AADAPT (digital asset threats)
  - ATLAS (AI and machine learning threats)
