# TryHackMe – SOC Role in Blue Team

This folder contains my personal notes and documentation from the **SOC Role in Blue Team** room on TryHackMe.

The room builds on the SOC L1 analyst role introduced earlier and explores where it fits within a company's overall security structure — who oversees the team, what other security departments exist, and what a realistic career path looks like.

---

## 🛡️ Topics Covered

- Security hierarchy of a company (Executives, CISO, Security Managers, Technical roles)
- Main security departments:
  - Red Team
  - GRC Team
  - Blue Team
- Blue Team structure and roles:
  - Security Operations Centre (SOC) – L1/L2 Analysts, Engineers, Manager
  - Cyber Incident Response Team (CIRT / CSIRT / CERT)
  - Specialized defensive roles (Digital Forensics, Threat Intelligence, AppSec, AI Researcher, DevSecOps, GRC Auditor)
- Advancing a SOC career:
  - Core SOC skills and CTF practice
  - SAL1 certification
  - Internal SOC vs MSSP
  - Next steps after SOC L1 (L2, Engineering, CIRT, Management)
- Practical role-matching challenge: assigning the right security professional to real-world incidents
