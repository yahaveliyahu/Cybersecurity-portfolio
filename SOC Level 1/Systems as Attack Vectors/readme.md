# TryHackMe – Systems as Attack Vectors

This folder contains my personal notes and documentation from the **Systems as Attack Vectors** room on TryHackMe.

The room continues the **SOC analyst** track by focusing on systems (rather than humans) as attack surfaces — how threat groups target them, and what a SOC analyst can do to keep an organisation secure.

---

## 🛡️ Topics Covered

- The role of a system in a modern digital world, and why the value of a breach depends on what was breached
- Three common attack vectors on systems:
  - Human-Led Attacks (weak/reused passwords, malicious USB devices)
  - Vulnerabilities (CVEs, zero-days, exploited-in-the-wild flaws)
  - Supply Chain Attacks (compromised apps/libraries pushed to all users)
- Deep dive into software vulnerabilities:
  - CVE lifecycle and numbering
  - Zero-days
  - Notable Windows CVEs (EternalBlue, BlueKeep, Zerologon, PrintNightmare, Follina)
  - Responding to vulnerabilities (patching, temporary mitigations, IPS/WAF rules)
- Misconfigurations:
  - How weak setups (not software bugs) create breaches
  - Responding via penetration testing, vulnerability scans, and configuration audits
- Mitigation strategy: combining Patch Management, IT Training, Network Protection, and Antivirus Protection
- Practical incident triage and remediation planning in a simulated SOC dashboard
