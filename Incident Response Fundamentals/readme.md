# TryHackMe – Incident Response Fundamentals

This folder contains my personal notes and documentation from the **Incident Response Fundamentals** room on TryHackMe.

The room introduces the fundamentals of **incident response**, focusing on how organisations identify, prioritise and handle cyber security incidents from start to end, and includes a hands-on lab investigating a phishing incident.

---

## 🛡️ Topics Covered

- Events, alerts and incidents
- False Positives vs True Positives
- Incident severity levels (Critical, High, Medium, Low)
- Common types of incidents:
  - Malware Infections
  - Security Breaches
  - Data Leaks
  - Insider Attacks
  - Denial of Service (DoS) Attacks
- Incident response frameworks:
  - SANS (PICERL – 6 phases)
  - NIST (4 phases)
- Incident Response Plan and its key components
- Incident detection and response tools (SIEM, AV, EDR)
- Playbooks and Runbooks
- Hands-on phishing incident lab:
  - Identifying the threat vector (Email Attachment)
  - Finding all hosts with the malicious file
  - Quarantining the file on hosts where it was not executed
  - Investigating the host where it was executed
  - Analysing the process tree timeline of the infected host
