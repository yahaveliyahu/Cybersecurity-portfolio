# TryHackMe – Windows Fundamentals 1

This folder contains my personal notes and documentation from the **Windows Fundamentals 1** room on TryHackMe.

The room introduces the fundamentals of the **Windows operating system**, focusing on navigating the user interface, understanding core system components, and making changes to the system, with security context along the way.

---

## 🪟 Topics Covered

- Windows history and versions (XP, Vista, 7, 8.x, 10, 11, Windows Server)
- Accessing the lab via Remote Desktop (RDP)
- The **NTFS** file system and its features:
  - NTFS permissions (Read, Write, Modify, Full Control, etc.)
  - Alternate Data Streams (ADS) and Mark of the Web
- The Windows folder, System32, and environment variables (`%windir%`)
- User accounts and account types (Administrator vs Standard User)
- Local Users and Groups management (`lusrmgr.msc`) and built-in accounts
- Groups and permission inheritance
- User Account Control (UAC)
- Settings menu vs Control Panel
- Task Manager
