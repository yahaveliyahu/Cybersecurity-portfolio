# TryHackMe – Security Principles

This folder contains my personal notes and documentation from the **Security Principles** room on TryHackMe.

The room introduces the **core principles and concepts that information security is built on**, from the CIA triad and security models to trust principles, international standards, and cloud security responsibilities.

---

## 🛡️ Topics Covered

- The CIA Triad: Confidentiality, Integrity, and Availability
- Beyond CIA:
  - Authenticity and Nonrepudiation
  - The Parkerian Hexad (Utility and Possession)
- The DAD Triad: Disclosure, Alteration, and Destruction/Denial
- Security models:
  - Bell-LaPadula (confidentiality)
  - Biba (integrity)
  - Clark-Wilson (integrity)
  - Goguen-Meseguer and noninterference
- Defence in Depth (Multi-Level Security)
- Trust but Verify vs Zero Trust, including microsegmentation
- ISO/IEC 19249:
  - 5 architectural principles
  - 5 design principles
- Vulnerability vs Threat vs Risk
- The Shared Responsibility Model in the cloud (IaaS, PaaS, SaaS)
